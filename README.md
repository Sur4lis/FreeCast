# 二路自由 FreeCast

**画面你来选，解说听你的。**

FreeCast 是面向电脑端 Chrome / Microsoft Edge 的直播组合播放器扩展。将喜欢的解说、比赛画面和弹幕组合在一起，支持在本机进行 B 路 AI 人声过滤。

## 下载

打开本仓库的 **[Releases（发行版）](https://github.com/Sur4lis/FreeCast/releases)**，在 **Assets** 中下载：

`FreeCast_浏览器插件_v1.01_AI多平台版.zip`

GitHub 自动生成的 `Source code (zip)` / `Source code (tar.gz)` 是仓库快照，不是插件安装包。

## 功能

- 支持 B 站房间号，以及虎牙、斗鱼、抖音完整直播链接；直接解析，无需保留原直播标签页。
- 支持公开 HLS / FLV 直播直链，并尝试解析其他网页明确嵌入的直播流。
- A / B 两路音量与画面独立控制，小窗放大、拖动、缩放和主小窗互换。
- 手动校准时间偏移，并在可用缓冲内保持偏移；不自动识别比赛场景对齐。
- B 站弹幕接收、叠加与手动发送；其他平台暂不支持独立弹幕。
- 默认收藏炫神与哔哩哔哩英雄联盟赛事，可添加其他收藏。
- B 路本地 AI 人声过滤，提供“游戏音效优先”和“更强去人声”两种策略。

## 安装

1. 完整解压插件压缩包到固定位置。
2. Chrome 地址栏输入 `chrome://extensions`；Edge 输入 `edge://extensions`。
3. 开启 **开发者模式**，点击 **加载已解压的扩展程序**。
4. 选择含有 `manifest.json` 的 **FreeCast浏览器插件** 文件夹。
5. 点击浏览器工具栏的 FreeCast 图标打开播放器。

安装后请保留插件文件夹。当前为本地加载版，尚未上架扩展商店。

## 从旧版升级

FreeCast 延续原“三路GOAT”的插件身份与设置。关闭播放器，将新版文件夹内的文件覆盖到原先加载的插件目录，在扩展管理页点击刷新，再打开播放器。

**不要卸载旧扩展，不要同时加载第二个副本。** 原插件目录仍叫旧名字也可以，覆盖其内容即可延续收藏和设置。显示版本为 **1.01**，浏览器内部更新版本为 **1.1.3**。

## 登录与权限

在同一浏览器完成相应平台网页登录。首次连接非 B 站来源时，扩展请求网站访问权限，用于读取用户指定的直播页面、播放接口和动态 CDN。

扩展不扫描其他标签页或浏览历史，不在直播网页添加悬浮按钮。账号凭据不上传给开发者；网络请求直接到相应平台及其 CDN。收藏和设置存储在本机。

## 兼容性与限制

- AI 需要浏览器图形加速和硬件 WebGPU 支持，实际表现取决于设备与驱动。
- 去人声属于实验性功能，会增加同步缓冲，可能削弱游戏角色语音和部分音效。
- 其他小平台仅通用解析公开 HLS / FLV，不保证所有网站都可播放。
- 直播签名、登录验证、访问限制、网络及平台更新可能影响可用性。
- 当前提供电脑浏览器扩展，不提供安卓版本。
