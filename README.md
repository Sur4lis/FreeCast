# FreeCast · 二路自由

**画面你来选，解说听你的。**

自由组合两个直播间的画面、声音和弹幕，支持 B 站、虎牙、斗鱼、抖音及部分公开 HLS / FLV 直播源。

本项目采用 **Vibe Coding（AI 辅助编程）** 方式开发。

## 下载与安装

下载 [FreeCast_v1.10.zip](https://github.com/Sur4lis/FreeCast/releases/download/v1.10/FreeCast_v1.10.zip)，或前往 [发布页](https://github.com/Sur4lis/FreeCast/releases/tag/v1.10)。

适用于 Windows 的 Chrome / Microsoft Edge 120 或更新版本。

1. 将安装包解压到固定文件夹。
2. Chrome 打开 `chrome://extensions`；Edge 打开 `edge://extensions`。
3. 开启“开发者模式”，点击“加载已解压的扩展程序”。
4. 选择包含 `manifest.json` 的 **FreeCast浏览器插件** 文件夹。
5. 点击浏览器工具栏的 FreeCast 图标使用。

升级时关闭播放器，将新版文件覆盖到原插件文件夹，再在扩展管理页刷新，无需卸载。安装后请保留插件文件夹；GitHub 自动生成的 Source code 用于查看仓库文件。

## v1.10 更新

1. 添加直播回看：可选最长 5 分钟缓存，支持拖动进度、倍速播放和一键返回直播。
2. 添加懒人一键配置：默认、默认去人声、自定义，设置自动保存。
3. AI 支持去人声和只保留人声，可选择处理 A 路或 B 路。
4. 添加虎牙、斗鱼、抖音弹幕支持，修复头像、昵称和房间 ID 显示。
5. 优化 UI 布局：压缩顶部和侧栏，常规播放控件移到画面外，全屏控件渐隐，SC 展示更精简，时间偏移支持直接输入。
6. 收藏夹支持拖动排序，自动保存顺序。

## 使用说明

- 输入 A / B 直播源，点击“连接直播”。各路音频、画面、弹幕可独立开关，小窗支持放大、移动、缩放及主小窗互换。
- “一键配置”位于 AI 人声处理栏右侧，修改设置后自动保存为自定义；回看缓存默认关闭。
- A 声音慢了往左调，A 声音快了往右调，也可直接输入偏移秒数。时间轴需手动校准，随后保持设置的偏移。
- 弹幕接收支持 B 站、虎牙、斗鱼、抖音；发送仅支持 B 站。B 站支持图片表情和 SC，其他三平台支持文字及普通 Unicode 表情。
- 回看缓存仅保存在内存中，不导出录像。刷新、断开或切换直播源后重新积累。
- 首次接入其他平台需允许网站访问权限。插件沿用同一浏览器的网页登录状态；平台要求验证时，在官网完成后重试。画质以平台实际返回为准。
- AI 需要浏览器图形加速与硬件 WebGPU，在本机处理音频。人声分离为实验性功能，可能削弱部分游戏音效；许可与模型来源见安装包说明。
