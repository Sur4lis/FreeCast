# FreeCast

组合两个直播间的画面、声音和弹幕，支持 B 站、虎牙、斗鱼、抖音及公开 HLS / FLV 直播源。

## 下载与安装

[下载 v1.24 插件](https://github.com/Sur4lis/FreeCast/releases/download/v1.24/FreeCast_v1.24.zip) · [安卓 APK](https://github.com/Sur4lis/FreeCast/releases/download/v1.24/FreeCast_Android_v1.24.apk) · [更新说明](https://github.com/Sur4lis/FreeCast/releases/tag/v1.24)

1. 完整解压安装包。
2. 在 Chrome / Edge 的扩展管理页开启「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择包含 `manifest.json` 的「FreeCast浏览器插件」文件夹。

升级时覆盖原插件目录并刷新扩展，原有收藏和设置保留。请保留插件文件夹。

## 源码

`browser-extension/` 为浏览器插件源码。Node.js 22 或更新版本：

```sh
npm ci
npm run prepare:assets
npm test
npm run pack
```

随后可直接加载 `browser-extension/`，安装包输出到 `release/`。

模型和 WASM 不放入 Git 历史；准备命令从已发布的 v1.10 安装包提取相同依赖，并校验 SHA-256。v1.24 安装包已包含这些文件，无需额外下载。

AI 在本地运行，需要硬件 WebGPU 支持。第三方库及模型来源、许可见 [第三方说明](browser-extension/第三方说明.txt)。

## 自动对齐（开发中）

当前开发分支实现 [Issue #18](https://github.com/Sur4lis/FreeCast/issues/18) 中的 CPU 画面自动对齐，不依赖 AI 去人声或 WebGPU，也不额外请求直播流、上传画面。

- 默认只框选第三方 A 中来自官方画面的小窗或完整计时条，自动在官方 B 中定位；也可分别框选 A / B 的对应区域。
- 双选区会校正相对平移和大小差异，再比较共同覆盖的画面；框边无需完全一致。A 选区仍宜留在官方小窗内，混入无关背景可能无法确认。
- 连续确认匹配后更新现有时间偏移，支持取消和撤销。静止、重复、定位不唯一或证据不足时保持原偏移；换源、回看和手动调整会使当前匹配失效。
- 这是一次性校准，最多采样 90 秒，支持最终偏移 ±60 秒。选择计时器时需保留完整“分:秒”，两路必须来自同一场比赛。

`auto-sync.js` 负责选区、采样及偏移应用；`visual-sync-worker.js` 在 Worker 中运行匹配；`visual-sync-overlap.js` 用多帧结构估计双选区的统一缩放和平移，并提取最大共同矩形；`visual-sync-inset.js` 负责小窗定位与时间匹配；`visual-sync-core.js` 提供有界历史、稳定性判定和媒体时间到播放器偏移的换算。空间校正本身不构成时间匹配证据；锁定新几何后会清空旧的稳定性证据，重新确认时间差。校正后的固定结构允许同位置、同形状边缘的局部对比度差异，不允许为不同字形单独移动像素。

运行 `npm test` 验证算法与控制器，`npm run test:visual-sync` 运行不需要录像或 FFmpeg 的 16 组生成时钟回归。指定本地素材可运行完整 40 例；2026-10-30 结果为 **39/40**，21 个拒绝负例均未误对齐。唯一失败正例是 A 框混入官方小窗外背景，没有可靠匹配。入口、素材身份、容差及失败处理见 [回归测试说明](docs/visual-sync-testing.md)。录像和登录信息不随代码分发。

真实 BP 配对验证了没有游戏计时器时的匹配；完全没有共同官方画面的样本只验证“拒绝更新偏移”，不能恢复两路时间差。单选区 BP 在部分起播位置仍不稳定，建议先用双选区。已有本地动态 HLS 测试验证双选区识别及后续播放；公网平台和真实网络波动仍需实测，离线结果不代表任意直播的精度。

v1.24 的偏移调整基于播放位置。自动校准按正在显示的帧计算相对偏移，并锚定播放时钟，避免下载分段突增影响应用结果。当前自动对齐需先关闭两路 AI 人声处理；处理后的音画与输入流使用不同时间轴，尚未支持在 AI 开启时自动校准。
